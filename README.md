Neural Network Fundamentals and Training Behavior Analysis

This project demonstrates the implementation and analysis of a feed-forward neural network using a customer churn dataset.

The objective of this assignment is to understand:

Neural network architecture
Forward propagation
Loss calculation
Backpropagation
Weight and bias updates
Hyperparameter tuning
Model evaluation
Dataset

Dataset Used: customer_churn_nn.csv

Target Variable:

churn
0 = Customer Retained
1 = Customer Churned

Python

TensorFlow / Keras

Seaborn
